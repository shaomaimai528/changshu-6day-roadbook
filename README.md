# 常熟出发 6 天 5 晚自驾地图路书

2026 国庆期间，从苏州常熟出发的 6 天 5 晚自驾行程网页。页面是地图优先的单页应用，桌面端为左侧行程抽屉加主地图，移动端为全屏地图加底部可上拉详情面板。

## 路线

- `10/1`：常熟 → 乌镇东栅/西栅 → 临浦
- `10/2`：临浦 → 五泄 → 西施故里 → 横店
- `10/3`：横店秦王宫 → 清明上河图 → 广州街·香港街
- `10/4`：横店明清宫苑 → 圆明新园·春苑 或 梦幻谷
- `10/5`：横店 → 绍兴 → 东湖 → 仓桥直街
- `10/6`：绍兴 → 嘉兴月河 → 斜西街烧麦 → 可选子城遗址公园 → 常熟

住宿按日行程执行：临浦 1 晚、横店 3 晚、绍兴 1 晚，共 5 晚。横店住宿选万盛街核心区，三天不用搬家。

## 页面能力

- 地图展示每日路线、景点、住宿区、路线段距离和停留时间
- 点击日期、路线、景点或住宿，自动高亮当天内容并缩放到对应范围
- 地图路线直接标注“从哪里到哪里、多远、开多久”，点击后查看完整分段说明
- 详情面板展示逐日时间轴、路线距离、景点亮点、地方图片、美食图片、停车和预约提醒
- `10/4` 的圆明新园·春苑与梦幻谷作为并列二选一方案
- 移动端使用日期快捷栏加底部详情面板，可展开、收起并滚完整查看当天安排
- 同一天会写明到达、游览、吃饭、转场和入住的大致时间，方便按具体日期查看
- 底图暂时不可用时，路线、距离、景点和文字详情仍可查看

地图底图通过在线瓦片加载，不使用需要 API Key 的账户体系。路线几何点、距离、景点、住宿和全部行程文字都直接保存在 `index.html` 中。
页面只依赖网络加载第三方底图瓦片；路线、景点、住宿、时间轴和文字详情均保存在本地，底图失败也不会影响行程内容。

## 本地运行

页面是静态网页，可以用任意静态文件服务预览。由于底图通过在线瓦片加载，建议通过本地服务打开，而不是直接双击 `index.html`：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 图片来源

页面中的景点照片来自 Wikimedia Commons，许可与作者信息记录在 `image-credits.json`。

菜品和地方插画为项目本地生成的编辑示意图，不是实拍照片，页面会用“示意图”标记。它们只用于辅助识别菜品和地点，实际外观、口味、景观、季节和现场状态请以当天现场为准。

所有门票、预约、演出场次和临时管控信息请在出行前通过景区官方渠道再次核对。
