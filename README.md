# 常熟出发 6 天自驾路书（浙江版）

2026 国庆期间，从苏州常熟出发的两人油车自驾行程网页。浙江路线为唯一保留版本，旧苏北鲁南路线及相关图片已删除。

路线：常熟 → 乌镇 → 宁波 → 神仙居 → 横店 → 绍兴 → 南浔 → 常熟。

9/30 晚上 18:00 从常熟出发，当晚到乌镇西栅；10/1 至 10/6 按乌镇、宁波、神仙居、横店、绍兴、南浔的顺序推进，每天只换一次住宿，10/6 午间错峰返程。

页面为可直接打开的单页静态网页，包含：

- 逐日时间线与驾驶里程
- 浙江路线总览、每日重点与转场时间
- 自驾、停车、景区接驳和索道切换建议
- 需预约项目的明确标注与可勾选预约清单
- 住宿、加油、两人轮换驾驶和单日安全提醒
- 雨天、大风、拥堵、疲劳等备用方案
- 浙江沿线实景图，按日嵌入，支持懒加载与点击放大

预约清单的勾选进度保存在浏览器本地（localStorage），仅存于访问者自己的设备。

页面图片来自 Wikimedia Commons，许可与作者信息记录在 `image-credits.json`，图片说明中也保留了来源提示。图片只用于辅助识别景点和路线氛围，实际景观、季节和现场状态可能不同。

所有门票、预约、演出场次和临时管控信息请在出行前通过景区官方渠道再次核对。
