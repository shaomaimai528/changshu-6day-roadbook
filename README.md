# 常熟出发 6 天自驾路书（不早起版）

2026 国庆期间，从苏州常熟出发的 6 天油车自驾行程网页。

路线：常熟 → 连云港 → 日照 → 沂水 → 临沂 → 常熟。

9/30 晚上 18:00 后从常熟出发，当晚直接到连云港，不再在盐城住一晚。10/1 到 10/6 的白天行程均按“不早起、可以玩晚”安排，最早起床时间约 9:00，通常 10:00 后出发。热门景点集中在 3 天，并优先安排到 10:30 后或午后进入，避免清晨闹钟。

页面为单页静态网页，手机可直接打开，包含：

- 逐日时间线与驾驶里程
- 不早起版时间表与热门景点限时安排
- 逐日路书中的自驾、公交、打车、景区接驳、观光车与索道切换建议
- 需预约项目的明确标注与可勾选预约清单
- 住宿、加油、单司机安全提醒
- 雨天、大风、拥堵、疲劳等备用方案
- 逐日景区与美食实拍图，来源、作者和许可标注在图片下方
- 图片保持原始比例，并支持逐张点击放大查看

预约清单的勾选进度保存在浏览器本地（localStorage），仅存于访问者自己的设备。

所有门票、预约和临时管控信息请在出行前通过景区官方渠道再次核对。
